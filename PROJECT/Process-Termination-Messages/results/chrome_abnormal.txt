Test Case: Chrome Abnormal Termination

Procedure:
1. Close all existing Chrome windows/background Chrome processes.
2. Run ./process_monitor from src/.
3. Choose option 3.
4. Press ENTER when prompted.

Expected:
The program uses Windows taskkill /F /IM chrome.exe and reports forced/abnormal termination.

Note:
Windows Chrome is monitored externally from WSL, so a POSIX waitpid() exit status is not reported.
